# Images KPMP — Kidney

Place ici les 30 images PNG attendues par la page : 10 patchs H&E et, pour chacun, les sorties PAS des deux modèles.

Pour chaque numéro de patch de 01 à 10, ajoute :

- `patch_XX_he.png`
- `patch_XX_pas_model1.png`
- `patch_XX_pas_model2.png`

Exemple pour le patch 01 : `patch_01_he.png`, `patch_01_pas_model1.png`, `patch_01_pas_model2.png`.

Garde exactement ces noms quand tu ajoutes ou remplaces une image. La page l’affichera au prochain déploiement GitHub Pages.
