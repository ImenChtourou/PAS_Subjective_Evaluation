# Images utilisées par le site

Les images ne sont pas incluses ici : ajoute tes patchs H&E KPMP et les sorties PAS générées avec exactement les noms ci-dessous.

## Kidney — KPMP

Pour chaque numéro de patch de 01 à 10, ajoute trois fichiers PNG directement dans `images/kidney/` :

- `patch_XX_he.png` : image H&E KPMP
- `patch_XX_pas_model1.png` : PAS généré par Model 1
- `patch_XX_pas_model2.png` : PAS généré par Model 2

Exemple pour le patch 01 : `patch_01_he.png`, `patch_01_pas_model1.png`, `patch_01_pas_model2.png`.

Conserve les mêmes noms lorsque tu remplaces une image. Après l’envoi du commit et le redéploiement GitHub Pages, la page affichera le nouveau fichier.

## Breast et Lung

Si tu ajoutes ces tissus plus tard, le code attend la même convention dans `images/breast/` et `images/lung/`.

Le dépôt GitHub étant public, les images ajoutées à ces dossiers seront elles aussi visibles publiquement.
